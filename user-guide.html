EstiGen User Guide

Complete guide to generating electrical network construction estimates

🚀 Quick Start

Generate your first estimate in under 2 minutes:

  1. Log In - Use your assigned surveyor or admin credentials.
  2. Select Work Category - Choose between New Network, Repair & Maintenance, or Shifting
  3. Choose Voltage Level - Select 33 kV, 11 kV, DTR, LT 3-Ph, LT 1-Ph, or Special Structure
  4. Enter Quantities - Input the number of poles, structures, and equipment needed
  5. Add Project Details - Name your project and add prepared/surveyed by information
  6. Generate & Save - Click "Generate Estimate" to view results and save to your personal dashboard.

🔐 Authentication & Security

EstiGen uses a secure multi-user system to protect data and provide personalized experiences.

User Roles

👷 Surveyor

Standard access to generate, save, view, and download estimates. Cannot modify master data or user accounts.

🛠️ Administrator

Full access including the Admin Panel. Can manage material rates, structures, and user roles.

Security Policies

  • Session Security: You stay logged in for the duration of your work. Always logout when using shared devices.
  • Forced Password Reset: Administrators can flag accounts for a mandatory password change. If requested, you must update your password before accessing the generator.
  • Audit Trail: Every estimate saved is tagged with your user ID for accountability.

💼 Working with Estimates

My Estimates Dashboard

Your estimates are private to your account. You can access them anytime via the 👤 User Profile Dropdown in the top-right corner.

  1. Click your profile name/avatar in the header.
  2. Select 📂 My Estimates.
  3. Filter, search, or delete your previous work from this secure dashboard.

Saving an Estimate

  1. After generating an estimate, click the 💾 Save button
  2. The estimate is saved to your personal profile.
  3. You can reload these estimates later to make adjustments without starting over.

Downloading as PDF

PDF reports are generated locally for immediate download. They contain full breakdowns with materials, labour, and tax calculations.

⚙️ Admin Panel (For Administrators)

The Admin Panel is the "Brain" of EstiGen. Accessible only to Administrators via the profile menu.

Core Management Areas

  • Structures: Update the composition of standard structures (e.g., adding more bolts to a 33kV Pole).
  • Materials: Real-time updates to material codes and market rates (₹).
  • Labour: Manage labour activity codes and hourly/unit rates.
  • 👤 User Management: Promote surveyors to administrators, or force password resets for security compliance.
💡 Tip for Admins: Changes made in the Admin Panel reflect instantly for all users. Use caution when updating rates.

💡 Tips & Best Practices

For Better Organization

  • ✅ Naming: Use clear work names like "Burdwan Division - 33kV Line Shifting - Feb 2024".
  • ✅ Profile Management: Keep your password secure and update it periodically.
  • ✅ Review: Always review the GST and Contingency percentages before finalizing.
