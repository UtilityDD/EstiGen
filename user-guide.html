EstiGen User Guide

Complete guide to generating electrical network construction estimates

🚀 Quick Start

Generate your first estimate in under 2 minutes:

  1. Select Work Category - Choose between New Network, Repair & Maintenance, or Shifting
  2. Choose Voltage Level - Select 33 kV, 11 kV, DTR, LT 3-Ph, LT 1-Ph, or Special Structure
  3. Enter Quantities - Input the number of poles, structures, and equipment needed
  4. Add Project Details - Name your project and add prepared/surveyed by information
  5. Configure Additional Costs - Set GST, contingency, supervision, and cess percentages
  6. Generate! - Click "Generate Estimate" to create your detailed cost breakdown

📋 Detailed Step-by-Step Guide

Step 1: Select Work Category

Choose the type of electrical work you're estimating:

  • New Network - For brand new electrical line installations
  • Repair & Maintenance - For fixing or maintaining existing infrastructure
  • Shifting of Network - For relocating existing electrical lines
💡 Tip: The work category helps categorize your estimate for future reference and reporting.

Step 2: Select Voltage / Asset Type

Choose one or more voltage levels for your project:

  • 33 kV - High voltage distribution lines
  • 11 kV - Medium voltage distribution lines
  • DTR - Distribution Transformer installations
  • LT 3-Ph - Low Tension 3-Phase lines
  • LT 1-Ph - Low Tension 1-Phase lines
  • Special Structure - Custom or specialized structures
💡 Tip: You can select multiple voltage levels if your project spans different types. Click each card to select/deselect.

Step 3: Enter Structure Quantities

For each voltage level selected, you'll see available structures organized by type:

  • Poles - Support structures (PSC, RCC, steel, wood)
  • Stay Sets - Support systems for stability
  • Conductors - Wires and cables (specify type and length)
  • Hardware - Clamps, connectors, insulators
  • Transformers - Power transformation equipment
💡 Tip: Each structure shows its description. Enter only the quantities you need - leave others at 0.
⚠️ Note: Make sure quantities are accurate. Use your survey data or technical specifications.

Step 4: Name Your Project

Add important project metadata:

  • Work Name - Descriptive name (e.g., "33 kV Line Extension at Village XYZ")
  • Estimated Prepared By - Your name or department
  • Survey Done By - Name or team who conducted the survey
💡 Tip: Use clear, descriptive names. This helps when searching through saved estimates later.

Step 5: Configure Additional Costs

Set percentage-based additional costs:

  • GST - Goods and Services Tax (default: 18%)
    • Apply to: Material + Labour, Material Only, or Labour Only
  • Contingency - Buffer for unexpected costs (default: 3%)
  • Supervision Cost - Project supervision charges (default: 5%)
  • Cess - Additional tax/levy (default: 1%)
💡 Tip: You can adjust these percentages based on project requirements or local regulations.

Step 6: Generate Estimate

Click "Generate Estimate" to create a detailed cost breakdown showing:

  • Material costs with quantities and rates
  • Labour costs with quantities and rates
  • Subtotals for materials and labour
  • All additional costs calculated
  • Grand total in numbers and words

💼 Working with Estimates

Saving an Estimate

  1. After generating an estimate, click the 💾 Save button
  2. The estimate is saved to the database with a unique ID
  3. You'll see a confirmation message with the estimate ID

Viewing Saved Estimates

  1. Click 📂 Saved Estimates in the header
  2. Browse the list of all saved estimates
  3. Use the search box to filter by ID, name, or category
  4. Click the 👁️ (eye) icon to view/load an estimate
  5. Click the 🗑️ (trash) icon to delete an estimate

Downloading as PDF

  1. After generating an estimate, click 📥 Download
  2. A PDF file will be created and downloaded to your computer
  3. The PDF includes all details: materials, labour, costs, and totals
  4. Perfect for printing, emailing, or archiving

Editing an Estimate

  1. After generating, click the Edit button
  2. You'll return to Step 5 (Additional Costs)
  3. Modify percentages or go back to change quantities
  4. Click "Generate Estimate" again to update

💡 Tips & Best Practices

For Accurate Estimates

  • ✅ Conduct thorough site surveys before estimation
  • ✅ Double-check all quantities from technical specifications
  • ✅ Use appropriate structure types for the terrain and load
  • ✅ Account for special conditions (crossing, river, etc.)
  • ✅ Review material and labour rates periodically

For Better Organization

  • ✅ Use descriptive project names (include location, voltage, date)
  • ✅ Save estimates regularly as you work on them
  • ✅ Maintain consistent naming conventions
  • ✅ Delete old or incorrect estimates to keep database clean

For Efficiency

  • ✅ Load similar past estimates as templates
  • ✅ Keep standard percentages (GST, contingency) saved as defaults
  • ✅ Use the search function in Saved Estimates for quick access
  • ✅ Download PDFs even if saving to database (backup)
⚠️ Rate Limiting: You can generate a maximum of 1 estimate per minute to protect server resources. If you need to generate multiple estimates, please wait 60 seconds between each generation.

🔧 Troubleshooting

Common Issues & Solutions

Problem: "No structures showing in Step 3"

Solution: Make sure you've selected at least one voltage level in Step 2. Go back and click on a voltage card.

Problem: "Estimate won't generate"

Solution: Check that you've:

  • Selected a work category (Step 1)
  • Selected at least one voltage level (Step 2)
  • Entered at least one quantity > 0 (Step 3)
  • Filled in all required fields in Step 4

Problem: "Rate limit exceeded"

Solution: You've generated an estimate in the last 60 seconds. Wait 1 minute before generating another estimate. This limit protects server resources.

Problem: "PDF download not working"

Solution: Check your browser's download settings and popup blocker. Allow downloads from this site.

Problem: "Can't find my saved estimate"

Solution: Use the search box in Saved Estimates page. Try searching by:

  • Estimate ID
  • Part of the work name
  • Work category (New Network, Repair & Maintenance, etc.)

Problem: "Numbers don't add up correctly"

Solution: Verify:

  • Material and labour rates are current (check Admin Panel)
  • Additional cost percentages are correct
  • The "Apply To" setting for each cost type is appropriate

⚙️ Admin Panel (For Administrators)
